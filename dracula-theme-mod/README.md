# dracula-theme-mod

Restyles the Claude Code transcript in Dracula colours.

- Tool calls are drawn as cards, with the tool name and its arguments.
- Status lines are coloured, and turn timings are shown.
- Inline code is drawn as a pill.
- Headings, bold and italic text use Dracula colours.
- The final reply of each turn has a faint frame, and text between your prompt and that reply is dimmed.
- Replies are drawn without the opening dot.

It has no options or commands.

## Install

```
/plugin install dracula-theme-mod --marketplace xRyul/claude-plugins-and-mods-by-xryul
```
